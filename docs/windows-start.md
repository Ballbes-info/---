# Запуск на Windows

1. Установите Node.js 22+ с официального сайта https://nodejs.org/ и перезапустите VS Code.
2. В PowerShell из корневой папки проекта выполните `powershell -ExecutionPolicy Bypass -File .\start-server.ps1`. Этот флаг действует только на данный процесс и не меняет постоянные настройки.
3. При первом запуске скрипт запросит ключ авторизации GigaChat и пароль доступа. Они сохраняются только в локальном `server/.env`, который исключён из Git. Не отправляйте этот файл другим людям.
4. Оставьте окно сервера открытым. Расширение автоматически обращается к `http://localhost:3000`. При открытии плавающего окна введите свой пароль прямо в нём и нажмите «Войти».
5. Откройте vgaranov.ru, нажмите Ctrl+Shift+Y, затем «Решить».

Локальный сервер работает только на этом компьютере. Для установки на другом компьютере без API-ключа нужен постоянно доступный HTTPS-сервер. В финальной сборке его адрес вшивается автоматически скриптом сборки; ключ и пароль в ZIP не попадают.

После обновления расширения браузер может сохранить старую пользовательскую привязку клавиш. Для чистой установки используется Ctrl+Shift+Y; уже назначенную привязку можно изменить в настройках сочетаний браузера.
