# Политика обработки данных — черновик

Перед публикацией владелец должен указать контакт и дату, проверить условия поставщика ИИ.

После нажатия «Решить» на vgaranov.ru читается текст, формула и таблицы текущего задания. Поддерживаемые задачи на логику, кодирование, память и прямоугольные следы Черепахи вычисляются локально без передачи в ИИ. Для остальных заданий сначала предлагается отдельная кнопка «Отправить в GigaChat». Только её нажатие передаёт текст и снимок области задания напрямую в GigaChat; на других сайтах используется снимок видимой части вкладки. Основная кнопка «Решить» не вызывает API автоматически. Своего сервера у расширения нет. На снимке могут находиться личные данные; пользователь должен проверить страницу до отправки. Фоновых снимков, аналитики и рекламы в проекте нет.

В пакете расширения содержится зашифрованный ключ API владельца. Вводимый пароль используется локально для расшифровки и не передаётся GigaChat. После разблокировки открытый ключ находится в памяти браузера в доверенном контексте расширения до блокировки, удаления, перезагрузки расширения или окончания браузерной сессии. Ключ отправляется только узлу авторизации GigaChat по HTTPS для получения токена. В ответах странице секреты не выдаются.

Снимки и ответы не записываются расширением на диск. Для снимка используется файловое хранилище GigaChat; после запроса расширение запрашивает удаление файла, включая случаи ошибки модели. Сбой сети может помешать удалению. Обработка и техническое хранение поставщиком регулируются его условиями.

Скрытие окна очищает ответ, но не отменяет уже отправленный запрос. В настройках есть кнопка блокировки, удаляющая разблокированный ключ из памяти профиля. Существующий запрос может завершиться до блокировки.

Для графов может передаваться исходная картинка диаграммы со страницы вместо всего снимка. ИИ извлекает подписи и рёбра, сопоставление с числовой таблицей проверяется локально. При неудаче допускается одна повторная попытка распознавания.

Для заданий с файлами после «Решить» расширение может скачать открытый XLSX или TXT по ссылке в условии с vgaranov.ru/download/. Файл обрабатывается в памяти, не отправляется в GigaChat при локальном решении. Сайт получает обычный запрос к своему файлу.
