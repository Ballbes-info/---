# Ручная проверка перед публикацией

- Яндекс на Linux: установить локальную папку, проверить сочетание Alt+Shift+E.
- На старте нет панели, снимков и сетевых запросов.
- Панель появляется справа сверху, перемещается ручкой; ответ не мешает кнопке.
- Войти по паролю, перезапустить браузер, проверить сохранённую сессию.
- После «Решить» панель не попадает в снимок, возвращается со статусом «Решаю…».
- ОГЭ: числовая задача; ЕГЭ: таблица, граф, код; сравнить с известным ответом.
- Переход на следующий вопрос и повторное нажатие дают новый снимок.
- Скрыть окно во время запроса, открыть снова: старый ответ не появляется.
- Проверить неверный пароль, истёкшую сессию, недоступный сервер, исчерпание квоты, нечитаемое условие.
- Переключить вкладку во время снимка: не отправлять снимок другой вкладки.
- На внутренней странице браузера расширение не должно падать с необработанными ошибками.
- Проверить на фактической версии Яндекса наличие activeTab, scripting, captureVisibleTab, optional_host_permissions и commands.
- В окончательном ZIP manifest.json находится в корне, секретов нет, адрес сервера постоянный.

Нельзя считать эти пункты пройденными без ручной проверки.
