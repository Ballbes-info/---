# Подготовка на Windows

1. Установите Node.js 22+ с https://nodejs.org/ и перезапустите VS Code.
2. Обновите копию репозитория (`git pull`, если клонировали Git).
3. Откройте PowerShell в корневой папке проекта.
4. Выполните `powershell -ExecutionPolicy Bypass -File .\prepare-extension.ps1`.
5. Введите ключ авторизации GigaChat (без Basic), затем выбранный пароль. Ввод скрыт. Не присылайте ключ в чат.
6. Обновите расширение в `browser://extensions` и перезагрузите вкладку с заданием.
7. Нажмите Ctrl+Shift+Y, введите пароль в маленьком окне, нажмите «Войти», затем «Решить».

Сервер не нужен. На других компьютерах достаточно установленного собранного расширения; Node.js нужен только владельцу для упаковки. Пароль требуется после перезапуска браузера. Никогда не публикуйте ключ в открытом виде или пароль вместе с ZIP.
