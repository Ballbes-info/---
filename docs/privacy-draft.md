# Политика обработки данных — черновик

Перед публикацией владелец должен указать своё имя/контакт, адрес сервера, хостинг, дату и проверить условия поставщика ИИ.

Расширение отправляет видимую часть активной вкладки только после нажатия «Решить». На снимке могут находиться личные данные: пользователь должен проверить страницу до отправки. Снимок поступает на сервер владельца и в GigaChat для получения ответа. В фоне страницы не снимаются. Само окно исключается из снимка.

Сервер обрабатывает снимок в памяти, не сохраняет его на диск и запрашивает удаление загруженного файла в GigaChat после запроса. Удаление может не выполниться при сбое связи; обработка и техническое хранение поставщиком регулируются его условиями. Ответ возвращается в расширение и не сохраняется в его постоянном хранилище.

Адрес сервера и токен входа сохраняются локально в профиле браузера. Пароль передаётся серверу по HTTPS при входе, расширение его не сохраняет. API-ключ GigaChat хранится только в настройках сервера. Сервер/хостинг могут обрабатывать IP и технические журналы; фактические сроки и настройки должны быть уточнены владельцем.

«Выйти» удаляет локальный токен. Скрытие окна очищает ответ на странице, но не отменяет уже отправленный запрос. Аналитика и реклама в код не включены.
