# Публикация варианта без сервера

1. Запустите prepare-extension.ps1 локально. Введите ключ и пароль; не коммитьте private-key.vault.json и ZIP.
2. Пройдите ручной чек-лист на Яндексе/Linux с реальным ключом и доступной моделью.
3. Проверьте готовые иконки и подготовьте реальные скриншоты, завершите политику конфиденциальности и разместите по публичному HTTPS-адресу.
4. Загрузите dist/gr-vasya-1.0.0.zip в кабинет Chrome Web Store, описание и скриншоты. Объясните activeTab/scripting/storage, чтение файлов vgaranov.ru/download/ и доступ к двум узлам GigaChat, раскройте передачу текста текущего задания и снимков GigaChat.
5. Предоставьте модератору тестовый доступ через закрытое поле инструкций. Не публикуйте пароль в описании.
6. Отправьте на модерацию после проверки владельцем.

ZIP включает зашифрованный ключ. Любой получивший ZIP может подбирать пароль офлайн; нельзя обещать абсолютную защиту общего ключа. Соответствие политикам магазина и одобрение не гарантированы. Репозиторий GitHub сам по себе не публикует расширение в магазине.
