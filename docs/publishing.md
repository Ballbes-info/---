# Подготовка магазина

Цель: установка по ссылке из Chrome Web Store в совместимом Яндекс Браузере на Linux. Фактическая совместимость и одобрение модерацией не гарантированы.

1. Развернуть HTTPS-сервер, внести ключ и пароль через секреты хостинга.
2. Пройти ручной чек-лист на Linux/Яндексе и реальный GigaChat-тест.
3. Собрать ZIP с постоянным адресом сервера.
4. Подготовить оригинальные иконки 16/32/48/128 px и добавить их в manifest; сделать реальные скриншоты работы.
5. Завершить политику конфиденциальности и разместить по публичному HTTPS-адресу.
6. В кабинете разработчика описать единственную функцию, объяснить activeTab/scripting/storage и доступ к серверу, раскрыть передачу снимков серверу и GigaChat.
7. Дать модератору рабочий тестовый доступ к серверу. Не помещать основной секрет в общедоступное описание.
8. После назначения ID настроить ALLOWED_EXTENSION_IDS; разрешить ID тестовой и опубликованной сборок при необходимости.
9. Отправить на проверку. Публикацию выполнять после проверки итоговых материалов владельцем.

Репозиторий GitHub сам по себе не публикует расширение в магазине и не запускает сервер. GitHub Pages не подходит для хранения API-ключа и серверного кода.
