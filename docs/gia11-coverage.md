## Что проверено

- Первый набор: по одному примеру каждого подтипа. 20 текстовых вычислений и два задания с файлами совпали с видимыми ответами сайта; граф проверялся отдельно со структурированными связями.
- Дополнительные наборы: ещё 58 текстовых примеров; все совпали. Итого 78 текстовых примеров.
- По реальным файлам: четыре запроса к «Продуктам» и два к последовательности. Ответы: 8400; 73246; 273; 1336; `6940 19789`; `1081 19320`.
- Итоговый проход на новых числах: 8/8 на сайте без GigaChat.
- 43 автотеста, включая криптографию, ZIP, XLSX, очистку состояния и запрет автоматического ИИ.

## Чего эти проверки не устанавливают

Полного перебора всех внутренних шаблонов генераторов не было. Реальное качество чтения новых графов моделью, установка этой версии в Яндекс/Linux и полный проход всех задач через упакованное расширение с ключом владельца в среде разработчика не проверены. Надпись 1.0.0 — номер первого выпуска с описанным покрытием, а не гарантия любого ответа.
